## 五、作业避坑指南
1.  **验证集划分**：必须从 `train` 文件夹中按8:2重新划分，不能直接用原始 `val` 文件夹（仅16张图片，无参考价值）
2.  **类别不平衡**：数据集肺炎样本远多于正常样本，报告中需说明此问题，且必须提交Precision/Recall/F1指标，不能仅提交准确率
3.  **医学场景指标**：肺炎诊断中**召回率（Recall）比准确率更重要**，因为假阴性（漏诊肺炎）的后果远大于假阳性（误诊）
